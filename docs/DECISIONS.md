# Decisions

Choices the brief left open, recorded so reviewers can check the code against them.

| # | Question | Decision | Where it lives |
|---|----------|----------|----------------|
| 1 | ¥5,000 × 6 = ¥30,000 does not cover ¥35,000. Must a plan cover the balance? | Yes. A plan is a monthly amount; the schedule is `ceil(balance / monthly)` payments and the last one is the remainder. ¥5,000 a month needs 7 payments and is rejected. The smallest acceptable amount, rounded up to a speakable ¥1,000, is ¥6,000 × 5 + ¥5,000. | `domain/terms.py` |
| 2 | "First payment within 45 days" — from when? | From the day of the call, inclusive: a call on 2 Oct allows a first payment from 2 Oct to 16 Nov. | `domain/terms.py` |
| 3 | Is 21:00:00 inside "08:00 to 21:00"? | No. The window is `08:00 <= t < 21:00` Japan time (UTC+9, no DST), matching the usual reading of the night-time contact restriction. | `domain/calling_hours.py` |
| 4 | Recording notice vs "never store audio" | The notice says the call is kept **as a text transcript** for 30 days, not that it is recorded as audio (録音). | `content/script_ja.yaml` |
| 5 | Greeting vs "someone else answers: disclose nothing" | Before identity is verified Kenji uses only the neutral name 「みなと」 and never mentions debt, collection, the amount or the account. The full name みなと債権回収 is used only after verification. | `content/script_ja.yaml`, flows |
| 6 | Source of English subtitles | Scripted lines carry their English in the script file. Model-generated lines and caller lines are translated asynchronously by a small model behind a `Translator` port; subtitles may lag the Japanese by a moment and never delay speech. Demo mode replays recorded subtitles. | `app/`, `adapters/` |
| 7 | Browser calls have no cap in the brief | Browser calls share the guardrails: 5 minutes per call, 3 calls a day per browser (hashed client address), and a separate 60-minute daily pool. | config + `domain/` guardrails |
| 8 | Where reference screenshots live | Captures of third-party sites stay local (git-ignored) under `docs/design-refs/`; `DESIGN.md` records the URLs and measured values. | `.gitignore` |
| 9 | Prebuilt client vs custom page | The Pipecat prebuilt client is a development tool only. The shipped page is the custom React app using the Pipecat client SDK. | `web/` |
| 10 | Where Cloudflare Workers fits | Decided in the deploy phase with current pricing; the static page is the natural candidate. | `README.md` |
| 11 | Strength of the 4-digit link code | Generated with `secrets`, single use, expires after 10 minutes, and a call gets 3 wrong attempts before linking is disabled for that call. | link registry |
| 12 | `make` on Windows | GNU Make for Windows (`winget install ezwinports.make`) or WSL. CI runs on Ubuntu. | `README.md` |
| 13 | Linguistic rule data in code | Kana readings, the aizuchi lexicon and honorific suffixes are rules, so they live beside the pure functions in `domain/`. Everything Kenji says, and every prompt, lives in `content/script_ja.yaml`. | `domain/`, `content/` |
| 14 | Cartesia's pronunciation features vs our own kana normaliser | Checked first, as the brief asks. Cartesia's [custom pronunciation dictionaries](https://docs.cartesia.ai/build-with-cartesia/capability-guides/custom-pronunciations) are plain search-and-replace and need an entry per string, so they cannot cover open-ended amounts and dates. Its [phoneme tags](https://docs.cartesia.ai/build-with-cartesia/capability-guides/phonemes) use an English-only phone set, and its [text normalisation](https://docs.cartesia.ai/build-with-cartesia/capability-guides/text-normalization) lists only English examples. Cartesia's own [Japanese page](https://cartesia.ai/languages/japanese) converts digits to kana before sending and advises writing ambiguous values the way they should be spoken. So amounts, dates, counters and account digits are rewritten to kana by a pure function, plugged into Pipecat's TTS `text_transforms` hook. Pipecat keeps the original text for the transcript and the model context; only the speech service sees kana. | `domain/kana.py`, `adapters/speech.py` |
| 15 | Date formatting outside the script file | Formatting dates and amounts (`10月27日`, `35,000`) is a rule like the kana readings, so it lives in code. Every sentence around them lives in the script. | `app/agreement.py` |
| 16 | Speech over Kenji while he reads back terms | It is judged only while Kenji is still speaking. Aizuchi and confirmations (はい, 間違いありません) are ignored there. Corrections and requests to change or repeat (違います, そうじゃなくて, いいえ, 変えたい, 変更, もう一度, 訂正) and requests to wait always interrupt. Other short speech below the read-back threshold is let pass; the read-back ends with a question, so the caller is asked again at once. Speech whose transcript arrives after Kenji has finished is a normal turn, so a はい at the end of the read-back is still heard as agreement. | `domain/turn.py`, `app/turns.py` |
| 17 | Two kinds of "locked" | `IdentityStatus.LOCKED_OUT` means three failed identity checks. The account view returns `LOCKED` while identity is not yet verified. | `domain/identity.py`, `domain/account.py` |
| 18 | Which language model | Any OpenAI-compatible chat-completions provider, chosen by `LLM_BASE_URL` and the three model settings; OpenAI by default. The demo runs on Meta's Muse Spark 1.3 contributor tier ($0.10 / $0.20 per million tokens). Muse Spark always reasons, so effort is `minimal` rather than `none`, and temperature is left at the provider default. The contributor tier lets Meta use the traffic to improve its models, which Kenji's spoken greeting, the page and the README state next to the 30-day deletion of our own records; callers are already asked not to share real personal data. Probed on 2026-10-02: the `developer` role and strict `json_schema` output work; time to the talker's first token is about 2.9 s median at `minimal` and 7.7 s at `xhigh`, so the talker stays at `minimal` and the 1.5 s budget is not met on this provider. | `.env.example`, `adapters/openai_models.py` |
| 19 | Japanese page copy | Labels and the plain-language "Now" sentences on the page (for example 本人確認, 通話の結果) are page copy, so they live with the page in `web/src/call/copy.ts`. Everything Kenji says stays in the script file. | `web/src/call/copy.ts` |
| 20 | Speech over the AI disclosure | Kenji's opening (the AI disclosure, the 30-day notice and the request not to share real details) cannot be interrupted: Pipecat's `FirstSpeechUserMuteStrategy` mutes the caller until it has played, so the disclosure is always given in full. Keypad presses are still read during it. | `app/call.py` |
| 21 | A phone call the guardrails refuse | It is refused at the signed webhook, before any media stream opens: Twilio says the refusal line (`Polly.Takumi` in Japanese, then `Polly.Matthew` in English) and hangs up. No speech recognition, synthesis or model runs, and the refusal is still recorded and audited. The media-stream check stays as a second line of defence. | `phone_routes.py`, `app/launcher.py` |
| 22 | Writing call records on Cloud Storage | Events and audit lines are written from one background thread per call, never on the event loop, and each file stays open until the call ends, because every open-append-close on the Cloud Storage volume re-uploads the object. A crash mid-call can lose that call's record. | `adapters/storage.py` |
| 23 | Traces and the 30-day promise | Pipeline tracing is on, but spans leave the server only when `OTEL_EXPORTER_OTLP_ENDPOINT` is set, and the deploy sets none. Pipecat's spans carry the caller's transcripts, the text Kenji speaks and the model's inputs and outputs, so an endpoint must keep traces for 30 days or less, or the deletion promise no longer holds. | `app/call.py`, `.env.example` |
| 24 | When a caller's turn ends | The first real calls ended turns on about 0.2 s of silence and forced Soniox to finalise there, so 「生年月日は、」 became a turn of its own and the date was lost. Production systems combine words and sound instead of a silence timer: Google's end-of-query model ([Shannon et al., 2017](https://www.isca-archive.org/interspeech_2017/shannon17_interspeech.pdf)), Alexa's acoustic, decoder and pause features ([Amazon Science](https://www.amazon.science/blog/alexa-scientists-address-challenges-of-end-pointing)), OpenAI's `semantic_vad` and Deepgram Flux. Kenji now uses Soniox's semantic endpointing (`vad_force_turn_endpoint=False`, `max_endpoint_delay_ms=1500`), keeps Silero VAD for the instant start that barge-in needs, and holds a turn open for 2 s more when the words stop on a topic or case particle, a pause comma or a filler. Japanese marks a finished turn at its end (です, ます, か), as the multilingual turn-taking work shows ([Inoue et al., 2024](https://aclanthology.org/2024.lrec-main.1036/)). Conjunctive endings (けど, から, ので) are not held, because callers often end a turn on them and imply the rest. Speech that resumes during the hold joins the same turn. A model-based incomplete-turn filter was rejected: it adds a model call to every turn. | `adapters/speech.py`, `app/turns.py`, `domain/turn.py` |
| 25 | Moving on from a step Kenji ends by speaking | The opening and the balance statement give way to the next step when the caller next speaks, not when Kenji's audio ends. Flows' deferred post-actions fired one turn late on real audio, because `BotStoppedSpeaking` reached the end of the pipeline before the `tts_say` finish marker, and an interruption dropped that marker and left every later step waiting. Scripted lines are therefore queued as plain speech through a custom action, and any step change cancels a pending one. | `app/flows.py`, `app/call.py` |
| 26 | Latency samples from before the opening | Pipecat's latency observer can time a turn from a voice-activity stop heard before the opening, while the caller is muted, which produced 40-second samples. A sample counts only if its turn started after the caller was first unmuted. | `app/call.py` |
| 27 | Reading back a plan with a smaller last payment | 「毎月6,000円を6回、最終回は5,000円」 can be heard as six payments of ¥6,000 plus a seventh. The read-back now names the regular payments and the last one separately (「毎月6,000円を5回、そのあと最終回に5,000円で、全6回」), and an even split has its own line. | `content/script_ja.yaml`, `app/agreement.py` |
| 28 | Where the strategist's offers come from | In a real call the strategist proposed ¥6,000 × 4 + ¥11,000 and ¥11,667 × 3, and the prompt's own example (¥6,000 × 6) was ¥36,000. The domain now lists the smallest acceptable plan and the next two ¥1,000 steps, each checked against the terms, and the strategist copies offers from that list instead of computing them. | `domain/terms.py`, `app/call_parts.py` |
| 29 | Turns that do not need the model | Following OpenAI's latency guide ("don't default to an LLM": constrained outputs can be hard-coded), the fast path answers from rules when it is sure: a full name and a matching date of birth, a monthly amount offer, and a plain yes to a plan Kenji just proposed or to the read-back. It calls the same tools the model would, so the terms, identity gate, audit and compliance checks are unchanged. Anything else goes to the model: a wrong or partial identity, timing it cannot read (来週, 月末), a restatement of the plan it just proposed, a lump sum, a date outside the terms, and any yes that is not a plain one. A turn the model answers cancels the plan the rules proposed. | `app/fast_path.py`, `domain/understanding.py` |
| 30 | Waiting on the model without sounding silent | A turn the model answers opens with 「はい、」 at once (OpenAI's "make your users wait less"). It stays out of the model's context, and Kenji keeps the floor until his answer has played: speech in that gap is judged as speech over him, so aizuchi cannot cancel the answer and a bare はい cannot be taken as agreement to something he has not said. The floor is released when his answer starts after the 「はい、」, when he stops speaking after the model has finished, when his turn closes, or when the caller really interrupts. | `app/fast_path.py`, `app/turns.py` |
| 31 | Muse Spark's slow tail | A talker request that has not streamed its first token after 2.5 s is raced by an identical second request, and the first to stream wins; the loser is closed before any of its output is used, so there is never a second reply or tool call. Thinking cannot be switched off: `reasoning_effort` `none` and `reasoning: false` return HTTP 400 in both the Chat Completions and Responses APIs. Muse Glimmer is open-weight and not on the Meta Model API. | `adapters/hedging.py`, `adapters/openai_models.py` |
| 32 | What the latency card measures | Each turn is timed from the caller going quiet to the first audio of Kenji's reply, and records whether he opened with rules, with 「はい、」 or with the model's words. When he did not wait on the model, the model stage is zero. | `app/latency.py`, `web/src/xray/LatencyCard.tsx` |
| 33 | A model that never answers | If the model has produced no words and no tool call 8 s after Kenji's 「はい、」, the stuck request is cancelled, Kenji says 「少々お待ちください。」 and the request is made once more; if that is silent too after another 8 s, Kenji apologises, asks the caller to say it again and gives the turn back. An empty completion counts as silence. This follows Google's Dialogflow CX (a bounded webhook timeout, a static partial response while waiting, a timeout event that triggers a fallback reply) and Pipecat's `retry_on_timeout` (re-issue once when no output arrives in time); LiveKit's issue #7448 shows the failure it prevents, an empty completion ending the turn in silence. In a heavy-load run of 24 real-model conversations the guard never had to fire. | `app/fast_path.py`, `app/turns.py` |
| 34 | Trying the phone line without a phone number | A browser softphone (Twilio Voice JavaScript SDK 2.18.5, pinned with a subresource hash) calls a TwiML App that points at the same signed webhook a number would. The call crosses Twilio's network, so the webhook signature, the 8 kHz Media Stream and keypad linking run exactly as for a phone; only the phone network leg is missing. It costs $0.0040 (SDK) + $0.0044 (stream) a minute against $0.0129 for a US number, needs no $1.15 monthly number, and lets a caller outside the US test without an international call. The token it mints can only call that TwiML App, lasts 10 minutes and uses one identity, so the per-caller daily limit still applies. The page and token are served only to a loopback client naming a local host with no forwarding headers, so the quick tunnel Twilio needs cannot reach them. | `softphone_routes.py`, `adapters/twilio.py`, `scripts/dev_server.py` |
| 35 | Testing outside calling hours | `scripts/dev_server.py --afternoon-in-tokyo` builds the call kit with a clock that reads 15:00 in Tokyo, the same clock `voice_check.py` uses. Only a script on the developer's machine can do this: no setting or environment variable moves the clock, so the deployed server always enforces 08:00 to 21:00, and the refusal keeps its own tests. | `scripts/afternoon_clock.py`, `scripts/dev_server.py` |
| 36 | ICE servers for a call on one machine | `dev_server.py` offers the browser no STUN or TURN server. With a STUN server, aioice waits up to 5 s per call for an answer on every network adapter, and one that cannot reach it (a Hyper-V or WSL switch) costs the full 5 s before Kenji can speak: 6 s from the button to his voice, against 2.4 s without. A browser and server on one machine connect on host candidates. The deployed server keeps STUN and TURN. | `scripts/dev_server.py` |
| 37 | A browser call Kenji cannot hear | The page asks for the microphone before it dials. If the browser blocks it, finds none, or finds it busy, no call is placed and the page says what to do, rather than opening a call in which Kenji talks to nobody. A server that cannot be reached is described in plain words, not as an ICE or offer error. | `web/src/call/useBrowserCall.ts`, `web/src/call/copy.ts` |
| 38 | A caller who needs time to think | A Hold button on a browser call keeps the caller's turn open however long they pause, and Done hands it to Kenji at once. It is push-to-talk's rule (the button, not silence, ends the turn) applied only when asked for, so every other turn keeps Soniox's endpointing. Pipecat's own watchdog closes a silent open turn after 5 s, so it is set to 30 s: Soniox closes every turn it heard words in within 1.5 s, so only a held turn, or one opened by noise with no words, waits longer. The page repeats the hold message every 15 s so the call is not closed as idle. Kenji is not cut off when Hold is pressed mid-sentence: the AI disclosure and the read-back must be heard in full. | `app/turns.py`, `adapters/speech.py`, `app/call.py`, `web/src/call/useBrowserCall.ts` |
| 39 | When Kenji's words reach the screen | His line appears as he starts saying it, not when he finishes: the output transport releases each sentence's text frame in step with the audio before it, and a scripted line's English is shown at once. The instant 「はい、」 and the holding line open the line of the answer that follows instead of standing alone. A sentence that starts just before the previous line is reported finished moves to its own line. | `app/transcript.py`, `app/observers.py` |
| 40 | Kenji announcing a scripted step | Words the model says in a response that hands over to a scripted step (identity check, read-back, promise, third party, handoff, stop, ending) are dropped with the whole response, so only the scripted line is heard. Instructions alone did not work on Muse Spark: naming the tools to stay silent before cut correctness to 20 of 24 runs, and a narrower sentence left narration unchanged. With the filter, the 12-scenario real-model check passed 24 of 24 twice, narrating lines fell from 25 to 14 (the rest are 「確認いたします」 while terms are checked), and the third-party and handoff calls have none. Muse sends a response in one burst, so holding it costs about 0.1 s. | `app/narration.py` |
| 41 | A subtitle that never comes back | A translation is tried twice, 10 s each. If both fail, the line says it has no English instead of showing 「Translating…」 for ever. | `app/transcript.py`, `web/src/xray/TranscriptLine.tsx` |
| 42 | The transcript beside the cards | The transcript is a card like the ones beside it and grows with the page; there is no scroll box inside the scrolling page (nested scrollbars are a known usability and accessibility trap). | 43 | Reading the audit record | It is shown as a timeline in plain words (what happened, when, and what was decided), with the raw hash-chained JSON one press away for anyone checking it. | `web/src/aftercall/auditTimeline.ts`, `web/src/aftercall/AuditCard.tsx` |
| 44 | Hearing the demo | The demo is a real call between Kenji and a synthetic Cartesia caller, recorded by `voice_check.py --record-demo`: the events the page received, and both sides of the audio mixed onto one track on the same clock (Kenji's lines start within 0.3 s of their events).
